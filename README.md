# Comic Book Hub

Frontend application for displaying educational comic books.

Where everyday concepts meet **fun storytelling**. Educational comics capturing the magic of classic cartoons. Discover fascinating everyday concepts explained through the familiar, fun style of classic childhood cartoons.
